Inheritance

A label matches every subtype. Query the supertype and the whole hierarchy answers — no multi-label bookkeeping.

MATCH (v:Vehicle) RETURN v.model, labels(v)

Relationship vector search

Embeddings live on relationships too, not just nodes.

MATCH (a)-[r:CITES]->(b)
RETURN a, r, b, vector.similarity(r.context_emb, $q) AS score
ORDER BY score DESC LIMIT 10

Every read query compiles to plain SQL that PostgreSQL plans itself. Open the SQL tab on any result frame, or run:
